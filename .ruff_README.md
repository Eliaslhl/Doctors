# 🔧 Ruff - Configuration du Linter/Formatteur

## 🚀 Utilisation

### Vérifier le code (Linting)
```bash
ruff check .
```

### Corriger automatiquement les erreurs
```bash
ruff check . --fix
```

### Formater le code
```bash
ruff format .
```

### Vérifier + Formater (recommandé avant un commit)
```bash
ruff check . --fix && ruff format .
```

## ⚙️ Configuration

La configuration se trouve dans `pyproject.toml` :

- **Longueur de ligne** : 100 caractères
- **Version Python** : 3.13
- **Règles activées** :
  - `E` : Erreurs de style (pycodestyle)
  - `W` : Warnings de style
  - `F` : Erreurs pyflakes
  - `I` : Tri des imports (isort)
  - `N` : Conventions de nommage PEP 8
  - `UP` : Suggestions de modernisation Python
  - `B` : Détection de bugs potentiels
  - `C4` : Simplifications de compréhensions
  - `SIM` : Simplifications de code

## 🔄 Intégration VS Code

L'extension Ruff est configurée pour :
- ✅ **Formater automatiquement** à la sauvegarde
- ✅ **Organiser les imports** à la sauvegarde
- ✅ **Corriger automatiquement** les erreurs simples

Les paramètres sont dans `.vscode/settings.json`.

## 🎯 Bonnes pratiques

1. **Avant de commiter** : Toujours lancer `ruff check . --fix && ruff format .`
2. **Pendant le développement** : Laisser VS Code formater automatiquement
3. **Pour les nouveaux fichiers** : Ruff s'appliquera automatiquement à la sauvegarde
